./projects.txt

Projects

Gsvp-dl | Google Street View Panorama Downloader

Github: https://github.com/yousephzidan/gsvp-dl

Gsvp-dl is a high-performance, asynchronous downloader for Google Street View panoramas. It provides both a command-line interface and a Python API, enabling users to bulk download panorama images (via their pano IDs) at configurable zoom levels. The tool is optimized for scaling up to millions of images.

FlowCare | Queue & Appointment Booking System Backend

Github: https://github.com/yousephzidan/flowcare-system/

Live: https://flowcare-rihal.tech/docs

FlowCare System is a high-performance, enterprise-grade REST API built with FastAPI and PostgreSQL, engineered to handle heavy queue and appointment booking traffic for service branches and clinics across Oman. Adhering to a clean MVC structural design, the system features a robust, branch-scoped Role-Based Access Control (RBAC) engine, precise business logic to prevent booking or shift overlaps, automated data seeding, and secure localized file storage for identity verifications. Complete with comprehensive audit logging and configurable data-retention pipelines, the production API is fully containerized via Docker and deployed live on cloud infrastructure.

Real-Time Chat Application

Github: https://github.com/yousephzidan/chat-app

The Real-Time Chat Application is an ongoing project focused on building a secure, full-stack private messaging platform that enables real-time communication with integrated voice and video calling. Developed using Flask, Python, Socket.IO, HTML, CSS, Javascript, and PostgresSQL, it aims to deliver a responsive and seamless user experience across devices. The system leverages Socket.IO for low-latency, real-time interactions and is being designed with scalability, reliability, and security in mind. Current development efforts are centered on refining the chat interface, optimizing real-time performance, and implementing advanced call handling features.

EcoPro-Nettoyage | Cleaning Services Frontend

Live: https://ecopro-nettoyage.vercel.app

EcoProNettoyage is a fully responsive, modern frontend web application designed for a commercial eco-friendly cleaning agency based in Paris. Built to showcase a seamless user experience, it features an interactive service showcase, clear tiered pricing grids, dynamic quote request forms, and a structured FAQ section. The project highlights clean component architecture, professional typography, and optimized asset delivery for desktop and mobile layouts.

AmaTrack | Amazon FBA Tracking Frontend

Live: https://amatracker.vercel.app/

AmaTracker is a sleek, client-side web application designed to track and manage progress, routines, or custom metrics efficiently. Built with a minimalist user interface, it features interactive data logging, real-time status updates, and local persistence to keep user data secure and instantly accessible without backend overhead. The project showcases clean component state management, responsive UI design, and optimized frontend performance.
